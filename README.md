## Overview

*Dalek Deterrence* is a self-directed Android game project inspired by classic Space Invader games and a certain New Year's Day encounter with some very determined extraterrestrial pepper pots.

Developed shortly after completing the **Android Basics Nanodegree by Google**, this project provided an opportunity to explore Android graphics programming, game loops, animation, collision handling, and custom drawing techniques beyond the Nanodegree curriculum.

The project combines original pixel artwork, Android graphics APIs, and a healthy dose of Doctor Who-inspired enthusiasm.

## Project Objective

The goal was to create a classic arcade-style Android game while learning low-level graphics and animation concepts.

The project provided practical experience with:

* Custom game loops
* Real-time rendering
* Sprite management
* Collision detection
* Score tracking
* Touch input handling
* Android graphics APIs

---

## Technical Concepts Explored

### SurfaceView and Rendering

The project uses Android's `SurfaceView` architecture to perform rendering on a dedicated thread.

Topics explored include:

* Creating a custom `SurfaceView`
* Implementing `Runnable`
* Managing rendering threads
* Locking and unlocking the drawing canvas
* Surface lifecycle management
* Pause and resume functionality

### Graphics Programming

The project provided hands-on experience with:

* Canvas rendering
* Bitmap management
* BitmapFactory
* Paint objects
* RectF objects
* Sprite drawing
* Animation workflows

### User Interaction

The game also includes:

* Touch controls
* Multiple game states
* Life management
* Score tracking
* Gameplay progression

## Design & Artwork

The pixel-art sprites were designed using Adobe Illustrator and various pixel-art techniques.

Helpful resources included:

* https://design.tutsplus.com/tutorials/render-a-simple-3d-pixel-space-invaders-in-adobe-illustrator--cms-21185
* https://design.tutsplus.com/tutorials/how-to-create-pixel-perfect-artwork-using-adobe-illustrator--cms-23907
* https://www.raywenderlich.com/2888-introduction-to-pixel-art-for-games

The goal was not only to build the game logic but also to create custom visual assets and experiment with retro arcade aesthetics.

## Why This Project Matters

Although small in scope, this project represents an important stage in my development as a programmer.

It was one of the first fully self-directed projects I undertook after completing the Android Basics Nanodegree and provided valuable experience with graphics programming, software architecture, user interaction, and creative problem solving.

More importantly, it reinforced the habit of learning new technologies by building things that were personally interesting.
